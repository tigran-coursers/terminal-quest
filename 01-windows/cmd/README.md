# CMD comparison

## Introduction and learning objectives

Recognize CMD instructions and compare CMD with PowerShell without using CMD for the main automation.

## Prerequisites

Windows Terminal with CMD and PowerShell profiles. Read the [Windows introduction](../README.md).

## Concepts and short examples

Open a CMD tab in Windows Terminal. Try `cd`, `dir`, `echo %PATH%`, and `where java`. Compare them with PowerShell’s `Get-Location`, `Get-ChildItem`, `$env:PATH`, and `Get-Command java`. Record at least two behavior or syntax differences. CMD is useful to recognize older Windows instructions, but write this homework’s Windows automation in PowerShell. Do not assume PowerShell aliases behave identically to CMD commands.
